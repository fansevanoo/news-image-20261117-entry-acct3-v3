A one-page newspaper front page summing up Tuesday 17 November 2026:
12 top stories with original flat illustrations, a world map showing
where each top story happened, and 36 further briefs — 48 verified
stories across 6 continents in total.

`main.py` draws the whole page with PIL only (no network, no
randomness, fully deterministic) and writes `entry.png` (1024x1024)
to `MAKEFUN_OUTPUT_DIR`. Run it with:

```
MAKEFUN_OUTPUT_DIR=. python3 main.py
```
